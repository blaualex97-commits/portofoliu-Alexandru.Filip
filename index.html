Development Journey

My progression from frontend fundamentals to larger React applications and more complete user experiences.

Step 01
Started with HTML and CSS, learning page structure, styling, responsive layouts and the fundamentals of building interfaces for the web.
Step 02
Moved into JavaScript and built interactive projects using DOM manipulation, events, filters, localStorage and dynamic UI updates.
Step 03
Built API-based projects such as Movie Search App and Weather App, working with fetch, async/await, external data and dynamic rendering.
Step 04
Started working with React, reusable components, props, hooks and state management, rebuilding previous concepts with a component-based architecture.
Step 05
Built MovieFlix, combining React, Tailwind CSS and the TMDB API to create a larger movie discovery experience with search, trailers, watchlist persistence and responsive UI.
Step 06
Built ExpenseFlow Pro, a React personal finance dashboard with transaction management, budgets, analytics, interactive charts, CSV export and persistent local data.
Step 07
Built ShopFlow Pro, my most complete frontend project so far, using React, Vite, Tailwind CSS, React Router, Context API and localStorage to create a responsive marketplace and price-comparison experience with multiple interconnected user flows.
